# ImageDiary 문제 해결

## 실행 파일이 열리지 않습니다

- ZIP을 완전히 압축 해제했는지 확인합니다.
- `ImageDiary.exe`만 옮기지 말고, 같은 폴더의 `_internal`을 포함한 전체 폴더를 유지합니다.
- Windows 보안 경고가 표시되면 파일의 출처와 다운로드 경로를 확인한 뒤 허용합니다.

## 시작했는데 이미지가 저장되지 않습니다

- 설정의 저장 경로가 존재하고 쓰기 가능한지 확인합니다.
- 외장 드라이브·네트워크 드라이브는 연결 상태와 여유 공간을 확인합니다.
- 캡처 대상이 전체 화면인지 메인 모니터인지 설정에서 다시 확인합니다.

## GIF가 생성되지 않거나 저장에 실패했습니다

- 저장 경로의 여유 공간과 쓰기 권한을 확인합니다.
- 생성 실패 안내에서 다시 시도를 선택합니다.
- 내부 원본이 남아 있으면 설정의 `이전 세션 GIF 다시 만들기`에서 세션을 선택해 다시 내보낼 수 있습니다.
- GIF 없이 종료한 세션은 미완료 세션으로 보관되며 같은 메뉴에서 처리할 수 있습니다.

## 내부 원본이 정리되었습니다

내부 원본은 `C:\temp\workdiary`에 저장되며, 자동 정리 정책 또는 사용자가 실행한 데이터 정리의 대상입니다. 자동 정리 설정에서 보존 세션 수·최대 용량·마지막 활동일 기준을 확인하세요. 사용자가 내보낸 GIF와 원본 이미지 폴더는 자동 정리 대상이 아닙니다.

## 프로그램이 예기치 않게 종료되거나 오류 메시지가 표시됩니다

가능하면 다음 정보를 함께 적어 [GitHub Issues](https://github.com/1-3127/ImageDiary/issues)에 제보해 주세요.

- 사용한 ImageDiary 버전과 Windows 버전
- 오류 메시지 전문 또는 화면 캡처
- 재현 순서
- 캡처 간격, 이미지 포맷, 내보내기 설정

내보내기 또는 복구 중 문제가 생긴 경우 내부 세션 폴더를 직접 삭제하지 마세요. 재현과 복구에 도움이 됩니다.
