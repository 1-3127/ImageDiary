# ImageDiary 버전별 구현 기능 목표

## 구현 상태

- v0.1: 구현 및 실환경 검증 완료
- 검증 완료: `YYMMDD-NN` 세션 폴더, 스크린샷 캡처, Animated GIF 생성·재생, 결과 폴더 자동 열기, UTF-8 한글 UI
- v0.2: 피드백 반영 및 자동 검증 완료, Windows 실환경 재검증 대기
- 실환경 확인 완료: 항상 위 고정, 사용자 지정 저장 경로, JPG 캡처
- Windows 로그인 시작은 전체 개발 종료 후 검증한다.

## 프로젝트 목적

작업 세션 중 시스템 시계에 맞춰 화면을 캡처하고, 세션 종료 시 시간순 이미지로 단일 Animated GIF를 생성하는 Windows 데스크톱 프로그램이다.

## 공통 원칙

- Python, PySide6, `mss`, Pillow를 사용한다.
- 캡처는 메모리에 보관하지 않고 내부 저장소에 즉시 파일로 저장한다.
- 캡처 시각은 상대 대기 시간이 아닌 시스템 시계의 60초(디버그), 15분 또는 30분 경계에 맞춘다.
- 스크린샷 파일명은 24시간 기준 `HHMM.<extension>`으로 저장한다. 파일명 오름차순이 GIF 프레임 순서다.
- 기능은 실제 사용에서 필요성이 확인될 때만 다음 버전에 추가한다.

## 저장 포맷 및 기본 저장 위치

### 캡처 포맷 판단

- v0.1의 기본 캡처 포맷은 PNG이며, v0.2부터 PNG/WebP/JPG를 선택할 수 있다.
- 15/30분 간격에서는 일반적인 단일 모니터 작업 세션의 프레임 수가 제한적이므로 PNG를 MVP의 기본값으로 사용해도 된다. 단, PNG 크기는 해상도와 화면 변화량에 따라 크게 달라진다.
- [추론] 4K 화면, 멀티 모니터, 고화질 이미지·영상 작업처럼 화면 정보량이 많은 환경에서는 장시간 세션의 PNG 누적 크기가 커질 수 있다. v0.2의 JPEG/WebP 선택으로 이를 줄일 수 있다.
- GIF 생성기는 입력 포맷과 독립적으로 동작하게 설계한다. 즉, 파일명 정렬 후 Pillow로 이미지를 열어 동일한 프레임 처리 경로를 사용한다.

### 내부 저장소와 사용자 제공 위치

- v0.2 내부 원본 루트는 `C:\temp\workdiary`로 고정한다.
- 세션 복구와 완료 여부 판정은 내부 원본만 사용한다.
- 사용자가 설정한 단일 저장 경로에는 내부 Screenshot과 GIF 원본의 복사본을 제공한다.
- 내부 세션 폴더 날짜가 보존기간 이상 지난 경우 정리한다. 기본 보존기간은 7일이며 향후 설정 UI에 노출할 수 있도록 변수화한다.

### 세션 경로

```text
<internal_root>/
└─ YYMMDD[-NN]/
   ├─ Screenshot/
   │  └─ HHMM.<extension>
   └─ Diary_HHMM-HHMM.gif
```

## 초기 설정값과 변수화 목록

다음 값은 코드 곳곳에 하드코딩하지 않고 `AppSettings`와 세션 시작 시점의 설정 스냅샷으로 분리한다. 설정은 항상 변경할 수 있지만 세션 중 변경된 값은 다음 세션부터 적용한다.

| 설정 키 | v0.1 값 | 사용자 설정 도입 | 용도 |
|---|---|---|---|
| `capture_interval_seconds` | `60`, `900`, `1800` | v0.1 | 60초 디버그 및 15/30분 캡처 경계 단위 |
| `internal_storage_root` | `C:\temp\workdiary` | 고정 | 복구 판단에 사용하는 내부 원본 루트 |
| `export_root` | Pictures/WorkDiary | v0.2 | 사용자에게 제공할 Screenshot/GIF 복사본 루트 |
| `capture_format` | `png` | v0.2 | `png`, `webp`, `jpg` 중 원본 캡처 포맷 |
| `image_quality` | `85` | v0.2 | JPEG/WebP 손실 압축 품질 |
| `internal_retention_days` | `7` | 추후 | 내부 원본 자동 정리 기준 |
| `capture_max_size` | 원본 크기 | v0.3 | 캡처 저장 전 최대 가로·세로 크기 |
| `gif_max_size` | 원본 크기 | v0.2 | GIF 인코딩 전 최대 가로·세로 크기 |
| `gif_frame_duration_ms` | `500` | v0.2 | GIF 프레임 표시 시간 |
| `gif_loop` | `0` | v0.2 | `0`은 무한 반복 |
| `capture_target` | 기본 전체 화면 | v0.3 | 전체 가상 화면 또는 선택 모니터 |
| `keep_screenshots` | `true` | v0.3 | GIF 성공 후 원본 보존 여부 |
| `open_output_on_finish` | `true` | v0.2 | 완료 후 세션 폴더 자동 열기 |

## v0.1 — 동작하는 MVP

### 목표

`Start → 자동 캡처 → Finish → GIF 생성 → 결과 폴더 열기`의 전체 흐름을 안정적으로 완성한다.

### 포함 기능

- PySide6 단일 창 UI
  - 캡처 간격: `60초 (디버그)`, `15분`, `30분`
  - Status
  - Captures count
  - Next Capture time
  - Start 버튼
  - Finish 버튼
- 세션 상태 전이
  - `IDLE → RECORDING → ENCODING → IDLE`
- Start 시 다음 시스템 시계 경계 계산
  - 60초: 매분 `:00`
  - 15분: 매시 `:00`, `:15`, `:30`, `:45`
  - 30분: 매시 `:00`, `:30`
  - 예: 19:07에 15분 모드로 시작하면 첫 캡처는 19:15
- `mss`를 이용한 기본 전체 화면 캡처 및 즉시 PNG 저장
- 세션 폴더 생성

  ```text
  <storage_root>/
  └─ YYMMDD[-NN]/
     ├─ Screenshot/
     │  └─ HHMM.png
     └─ Diary_HHMM-HHMM.gif
  ```

- Finish 시 PNG 파일을 파일명 기준으로 정렬하여 단일 Animated GIF 생성
- GIF 생성 뒤 결과 세션 폴더 열기
- 디스크 저장 및 GIF 인코딩 오류를 Status에 표시

### 제외 기능

- 중복 이미지 감지
- Screenshot 유지/삭제 선택
- 멀티 모니터 선택
- Preview
- 작업 제목/태그
- Idle 감지
- DB 및 AI 분석
- Timeline UI
- 세션 메타데이터 파일

### 완료 기준

- 60초, 15분 및 30분 모드의 다음 캡처시각 계산이 정확하다.
- 캡처 이미지가 세션의 `Screenshot` 폴더에 즉시 저장된다.
- Finish 후 생성된 GIF의 프레임 순서와 PNG 파일명 정렬 순서가 일치한다.
- 정상 완료 시 결과 폴더가 열린다.

### v0.1 모듈 경계

`WIP`에서 각 책임은 별도 Python 파일로 구현한다. UI 파일은 기능을 호출하고 상태를 표시할 뿐, 캡처·시간 계산·GIF 인코딩을 직접 수행하지 않는다.

```text
WIP/
├─ main.py                 # QApplication 생성 및 시작점
├─ app.py                  # MainWindow UI와 이벤트 연결
├─ session_controller.py   # 상태 전이와 세션 흐름
├─ capture_scheduler.py    # 다음 시계 경계 계산과 QTimer
├─ screenshot_capture.py   # mss 캡처 및 파일 저장
├─ gif_builder.py          # 정렬, 크기 통일, GIF 인코딩
├─ file_exporter.py        # 내부 원본을 사용자 경로로 복사
├─ data_cleanup.py         # 최신 2개 외 사용자 세션을 휴지통으로 이동
├─ retention.py            # 내부 원본 보존기간 정리
├─ session_recovery.py     # 최신 미완료 세션 판정
├─ recovery_dialog.py      # 복구/마치기 선택 UI
├─ gif_progress_dialog.py  # GIF 진행 팝업
├─ session_status_widget.py # 세션 상태 표시 UI
├─ settings_dialog.py      # 사용자 설정 UI
├─ settings_repository.py  # 설정 영구 저장
├─ startup_manager.py      # Windows 로그인 시작 등록
├─ storage.py              # 세션 폴더와 결과 경로 생성
├─ settings.py             # 설정값과 경로 계산
├─ tests/                  # 경계시각, 저장 경로, GIF 순서 자동 검증
└─ requirements.txt        # 실행 의존성
```

### 문서 및 변경 관리 규칙

- 구현 중 범위·기본값·완료 기준이 바뀌면 이 문서를 같은 변경 단위에서 최신화한다.
- Git으로 모든 변경 이력을 관리하며 기능 단위로 검증 후 push한다.

## v0.2 — 사용성 및 세션 신뢰성

### 목표

일상적으로 실행해도 세션 정보를 잃지 않고, 기본 조작이 더 편한 상태로 만든다.

### 포함 기능

- 최신 내부 세션 폴더에서 Screenshot 존재 및 GIF 부재를 검사해 비정상 종료 감지
- 미완료 세션에 `세션 복구`와 `세션 마치기` 제공
- 내부 원본을 사용자 지정 단일 저장 경로로 복사
- 내부 및 사용자 경로 모두에서 충돌하지 않는 `YYMMDD[-NN]` 세션명 선택
- PNG/WebP/JPG 포맷 선택, JPG/WebP 기본 품질 85
- 설정 창과 설정 영구 저장
- 캡처 간격을 설정 창에서 선택
- 세션 중 설정 변경 시 다음 세션부터 적용됨을 안내
- Windows 로그인 시 시작 토글
- 항상 위에 고정 토글과 마우스 오버 도움말
- GIF 생성 진행 상태를 별도 팝업으로 표시
- 7일 이상 지난 내부 세션 원본 자동 정리
- 데이터 정리 버튼으로 사용자 경로의 최신 2개 외 세션을 확인 후 휴지통으로 이동
- 메인 UI의 캡처 수와 다음 캡처를 `다음 시각 (순번)` 형식의 캡처 현황으로 통합

### 완료 기준

- GIF 생성 전 앱이 종료되어도 내부 이미지로 최신 세션을 복구하거나 마칠 수 있다.
- 큰 해상도의 캡처에서도 UI가 멈춘 것처럼 보이지 않으며 인코딩 상태를 확인할 수 있다.
- 사용자 설정 경로의 파일명을 임의로 바꿔도 내부 복구 판정에 영향을 주지 않는다.

## v0.3 — 캡처 제어와 출력 선택

### 목표
