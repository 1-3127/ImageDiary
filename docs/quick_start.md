# ImageDiary 간단 사용 설명서

1. 설정에서 캡처 간격, 대상 화면, 이미지 포맷을 선택합니다.
2. 시작을 누르면 즉시 한 장을 저장하고, 이후 시스템 시각 경계에 맞춰 자동 캡처합니다.
3. 종료 및 저장을 누른 뒤 내보내기 설정에서 GIF 이름·경로와 후처리를 정합니다.
4. `세션으로 돌아가기`는 기록을 계속합니다. 취소 후 종료하거나 GIF 생성에 실패한 세션은 설정의 `미완료 세션 GIF 저장`에서 다시 내보낼 수 있습니다.
5. 내부 이미지가 남은 완료 세션은 설정의 `이전 세션 GIF 다시 만들기`에서 선택해 GIF를 새로 만들 수 있습니다.

후처리(블러, 마스킹, 워터마크, 타임코드)는 GIF에만 적용되며 내부 원본 이미지는 변경하지 않습니다.
