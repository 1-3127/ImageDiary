- v0.2 Windows x64 `onedir` 패키징 및 실행 시작 검증 완료, 1분 디버그 옵션 포함

## 프로젝트 목적

작업 세션 중 시스템 시계에 맞춰 화면을 캡처하고, 세션 종료 시 시간순 이미지로 단일 Animated GIF를 생성하는 Windows 데스크톱 프로그램이다.

## 공통 원칙

- Python, PySide6, `mss`, Pillow를 사용한다.
- 캡처는 메모리에 보관하지 않고 내부 저장소에 즉시 파일로 저장한다.
- 내부 Screenshot 원본은 자동 보존기간 정리 또는 사용자가 실행한 데이터 정리 외에는 삭제하지 않는다.
- 시작 시 현재 화면을 즉시 캡처하고, 이후 시스템 시계 기준의 선택 간격 경계에 맞춰 캡처한다.
- 스크린샷 파일명은 세션 내 순번 기준 `NNN.<extension>`으로 저장한다.
- GIF 이미지와 복구 이미지 순서는 내부 파일의 수정 시각을 우선하고 파일명을 보조 기준으로 정렬한다.
- 기능은 실제 사용에서 필요성이 확인될 때만 다음 버전에 추가한다.

## 저장 포맷 및 기본 저장 위치

### 캡처 포맷 판단

- v0.1의 기본 캡처 포맷은 PNG이며, v0.2부터 PNG/WebP/JPG를 선택할 수 있다.
- 15/30분 간격에서는 일반적인 단일 모니터 작업 세션의 이미지 수가 제한적이므로 PNG를 MVP의 기본값으로 사용해도 된다. 단, PNG 크기는 해상도와 화면 변화량에 따라 크게 달라진다.
- [추론] 4K 화면, 멀티 모니터, 고화질 이미지·영상 작업처럼 화면 정보량이 많은 환경에서는 장시간 세션의 PNG 누적 크기가 커질 수 있다. v0.2의 JPEG/WebP 선택으로 이를 줄일 수 있다.
- GIF 생성기는 입력 포맷과 독립적으로 동작하게 설계한다. 즉, 수정 시각 정렬 후 Pillow로 이미지를 열어 동일한 이미지 처리 경로를 사용한다.

### 내부 저장소와 사용자 제공 위치

- v0.2 내부 원본 루트는 `C:\temp\workdiary`로 고정한다.
- 세션 복구와 완료 여부 판정은 내부 원본만 사용한다.
- 사용자가 설정한 단일 저장 경로에는 종료 시 GIF를 항상 복사하고, 설정에 따라 Screenshot 전체를 함께 복사한다.
- 최근 수정 세션 2개는 기간과 무관하게 보호하고, 나머지는 내부 마지막 활동 시각이 보존기간 이상 지난 경우 정리한다. 기본 보존기간은 7일이며 향후 설정 UI에 노출할 수 있도록 변수화한다.

### 세션 경로

```text
<internal_root>/
└─ YYMMDD[-NN]/
   ├─ Screenshot/
   │  └─ NNN.<extension>
   └─ Diary_<첫 이미지 수정시각 HHMM>-<마지막 이미지 수정시각 HHMM>.gif
```

## v0.1 — 동작하는 MVP

### 목표

`Start → 자동 캡처 → Finish → GIF 생성 → 결과 폴더 열기`의 전체 흐름을 안정적으로 완성한다.

### 포함 기능

- PySide6 단일 창 UI
  - 캡처 간격: `60초 (디버그)`, `15분`, `30분` (v0.1 당시 구성)
  - Status
  - Captures count
  - Next Capture time
  - Start 버튼
  - Finish 버튼
- 세션 상태 전이
  - `IDLE → RECORDING → ENCODING → IDLE`
- Start 시 다음 시스템 시계 경계 계산 (v0.1 당시 동작)
  - 60초: 매분 `:00`
  - 15분: 매시 `:00`, `:15`, `:30`, `:45`
  - 30분: 매시 `:00`, `:30`
  - 예: 19:07에 15분 모드로 시작하면 첫 캡처는 19:15
- `mss`를 이용한 기본 전체 화면 캡처 및 즉시 PNG 저장
- 세션 폴더 생성

  ```text
  <storage_root>/
  └─ YYMMDD[-NN]/
     ├─ Screenshot/
     │  └─ NNN.png
     └─ Diary_<첫 이미지 수정시각 HHMM>-<마지막 이미지 수정시각 HHMM>.gif
  ```

- Finish 시 PNG 파일을 파일명 기준으로 정렬하여 단일 Animated GIF 생성
- GIF 생성 뒤 결과 세션 폴더 열기
- 디스크 저장 및 GIF 인코딩 오류를 Status에 표시

### 제외 기능

- 중복 이미지 감지
- Screenshot 유지/삭제 선택
- 멀티 모니터 선택
- Preview
- 작업 제목/태그
- Idle 감지
- DB 및 AI 분석
- Timeline UI
- 세션 메타데이터 파일

### 완료 기준

- 60초, 15분 및 30분 모드의 다음 캡처시각 계산이 정확하다.
- 캡처 이미지가 세션의 `Screenshot` 폴더에 즉시 저장된다.
- Finish 후 생성된 GIF의 이미지 순서와 PNG 파일명 정렬 순서가 일치한다.
- 정상 완료 시 결과 폴더가 열린다.

## v0.2 — 사용성 및 세션 신뢰성 (완료)

### 목표

일상적으로 실행해도 세션 정보를 잃지 않고, 기본 조작이 더 편한 상태로 만든다.

### 포함 기능

- 최신 내부 세션 폴더에서 Screenshot 존재 및 GIF 부재를 검사해 비정상 종료 감지
- 미완료 세션에 `세션 복구`와 `세션 마치기` 제공
- 내부 원본을 사용자 지정 단일 저장 경로로 복사
- 내부 및 사용자 경로 모두에서 충돌하지 않는 `YYMMDD[-NN]` 세션명 선택
- PNG/WebP/JPG 포맷 선택, JPG/WebP 기본 품질 85
- 설정 창과 설정 영구 저장
- 시작 버튼을 누르면 현재 화면을 1번째 이미지로 즉시 캡처하고 이후 시스템 시계의 선택 간격 경계마다 캡처
- 캡처 간격을 설정 창의 슬라이더에서 10~30분 범위, 5분 단위로 선택하고 별도 1분 디버그 토글 제공
- 이미지 파일명은 세션 캡처 순번에 따라 `001`, `002`, `003` 형식으로 생성
- 이미지 수정 시각 기준으로 GIF·복구 순서를 결정하고 파일명은 동일 시각의 보조 기준으로 사용
- GIF 파일명은 첫 이미지와 마지막 이미지의 수정 시각을 24시간제 `HHMM`으로 변환해 `Diary_HHMM-HHMM.gif`로 생성
- 메인 캡처 현황을 `N번째 캡처까지: MMm` 형식의 남은 시간으로 표시
- 상태를 메인 창 상단의 고정/설정 버튼과 같은 줄에 표시
- `종료 시 이미지 전체 저장하기` 설정: 켜면 Screenshot과 GIF, 끄면 GIF만 사용자 저장 경로에 복사
- 세션 중 설정 변경 시 다음 세션부터 적용됨을 안내
- Windows 로그인 시 시작 토글
- 항상 위에 고정 토글과 마우스 오버 도움말
- GIF 생성 진행 상태를 별도 팝업으로 표시
- 내부 마지막 활동 시각 기준 최근 수정 세션 2개는 항상 보호하고, 나머지 중 7일 이상 지난 내부 원본 자동 정리
- 데이터 정리 버튼으로 내부 원본의 최신 2개 외 세션을 별도 확인창에서 다시 확인한 후 휴지통으로 이동
- 데이터 정리는 사용자가 설정한 저장 경로의 복사본을 변경하거나 삭제하지 않음
- 정밀 타이머와 경계 도달 재확인으로 예약 시각 직전 실행을 방지하고 동일 순번 파일 덮어쓰기 차단
- 메인 UI의 캡처 수와 남은 시간을 `N번째 캡처까지: MMm` 형식으로 통합

### 완료 기준

- GIF 생성 전 앱이 종료되어도 내부 이미지로 최신 세션을 복구하거나 마칠 수 있다.
- GIF 생성은 20분 간격·JPG 품질 85·이미지 30장 필드 테스트에서 병목 없이 완료됐다. 패키지 환경의 장시간·대용량 조건은 전체 개발 종료 후 베타 테스트에서 재검증한다.
- Windows 로그인 시작 토글은 최신 버전 필드 테스트에서 정상 동작을 확인했다.
- 사용자 설정 경로의 파일명을 임의로 바꿔도 내부 복구 판정에 영향을 주지 않는다.

### 포함 후보 기능

- 설정 초기화 버튼
  - 개발판과 패키지판이 공유하는 `QSettings` 값을 기본값으로 복원
  - 실행 전 확인 팝업을 표시하고 Windows 로그인 시작 등록도 함께 해제
  - 사용자 저장 경로의 결과물과 `C:\temp\workdiary` 내부 원본은 삭제하지 않음
  - 진행 중인 세션에서는 초기화된 설정을 다음 세션부터 적용
- 앱 크레딧·정보 창
  - 앱 버전, 실행 파일 경로, 빌드 날짜, 간단한 크레딧 표시
- 프로그램 내 도움말
  - 시작·종료·GIF 출력의 간단한 사용 방법과 내부 자동 정리 정책 표시
- 최소 캡처 단위 5분
  - 1분 디버그 옵션을 제거하고 5~30분 범위의 5분 단위 슬라이더로 통일
- 캡처 모니터 설정
  - 메인 모니터만 캡처 또는 현재의 전체 가상 화면 캡처 선택
- GIF 공유 후처리
  - 지정한 하나 이상의 사각형 영역을 블러 처리
  - 화면 전체에 반복되는 워터마크 문구와 투명도를 적용
  - 각 이미지에 내부 이미지 수정 시각 기반 24시간제 타임코드 표시
  - 파일명·경로가 노출될 수 있는 상단과 작업 표시줄이 있는 하단을 각각 지정한 픽셀만큼 크롭
  - 블러·워터마크·타임코드·크롭은 GIF 출력에만 적용하고 내부 Screenshot 원본은 수정하지 않음
- 기록 종료/GIF 생성 클릭 시 GIF 출력 설정 팝업
  - GIF 이름 입력: 기본값은 `Diary_HHMM-HHMM.gif`, 세션별 사용자 입력으로 변경 가능
  - 블러·반복 워터마크·상하 크롭·타임코드 적용 여부와 값을 설정
  - 타임코드는 `MM/DD HH:MM` 형식을 기본으로 하며 날짜(`MM/DD`) 표시 토글 제공
  - 첫 번째 토글은 외부 이미지 저장 여부, 두 번째 토글은 GIF와 같은 세션 폴더에 이미지 저장 여부
  - 이미지 저장을 켜고 같은 폴더 저장을 끄면 별도 이미지 저장 경로를 선택할 수 있음
  - 두 이미지 저장 토글은 기본값으로 켜고, 기존 설정 창의 이미지 전체 저장 토글은 출력 팝업으로 이동
- 모니터 선택 또는 가상 전체 화면 선택
- 캡처 이미지 최대 크기 설정
- 현재 세션의 캡처 목록 및 간단한 Preview
- 작업 제목과 태그 입력
- GIF 외 MP4 출력 옵션 검토

v0.3 실사용 테스트에서 확인된 문제를 보완하고, 정식 릴리즈 전 저장·복구·패키지 환경의 안전성을 검증한다.

### 포함 후보 기능

- GIF 생성 실패 시 원본을 유지한 상태로 재시도
- 2026-08-28: 예외 처리 단위를 시작한다.
  - 복구 세션에서 GIF 저장 설정을 취소하면 `.unfin` 숨김 마커를 남기고 IDLE로 복귀한다.
  - 설정 창의 `미완료 세션 GIF 저장`에서 마커가 있는 세션을 선택해 GIF 저장 설정을 다시 연다.
  - GIF 생성과 원본 이미지 저장 실패는 각각 재시도 안내를 표시한다. GIF 재시도를 포기한 세션은 `.unfin`으로 보관한다.
  - 캡처 저장 실패는 즉시 재시도를 안내하고, 저장 경로·설정 오류에는 설정 열기와 초기화 경로를 제공한다.
  - 처리되지 않은 예외는 오류 및 GitHub Issue 제보 절차를 표시한 뒤 프로그램을 종료한다.
  - 설정 창의 앱 정보에 GitHub 프로젝트 페이지 링크를 제공한다.
- GIF 저장 설정에는 `세션으로 돌아가기`와 `취소`를 구분한다. 전자는 기록을 재개하고, 후자는 GIF 없이 종료할지 확인한 뒤 미완료 세션으로 보관한다.
- 복구 팝업에서 `나중에`를 선택해도 `.unfin` 마커를 갱신한다. 설정 창에서는 미완료 세션뿐 아니라 내부 이미지가 남은 완료 세션을 선택해 GIF를 다시 만들 수 있다.
- GIF 없이 이미지만 내보낸 경우 내부 세션에 더미 `Diary_*.gif`를 만들어 완료 상태를 확정한다.
- UI 용어는 `GIF 저장 설정`·`저장 설정` 대신 `내보내기 설정`·`내보내기`로 통일한다. 메인/설정 도움말과 README는 미완료 세션 재시도, 완료 세션 GIF 재생성, 이미지 전용 내보내기의 완료 처리까지 안내한다.
- `설정 기억하기`는 후처리 옵션뿐 아니라 GIF 이름, GIF 내보내기 경로, 별도 이미지 내보내기 경로도 복원한다.
- 블러·마스킹·워터마크·타임코드의 현재 조합을 한 화면에 함께 보여 주는 통합 미리보기를 내보내기 설정에 제공한다. 이 미리보기는 설정 확인용이며 내부 원본에는 영향을 주지 않는다.
- 자동 정리는 기본값으로 최근 수정 세션 2개 보호 + 마지막 활동 7일을 유지한다. 설정에서 세션 수·할당 용량(MB)·마지막 활동일 기준을 각각 켤 수 있으며, 여러 기준을 함께 켜면 `OR` 조건으로 오래된 세션부터 내부 저장소만 정리한다.
- GIF 내보내기에서 재생 속도를 빠르게(0.5배)·기본(1배)·느리게(1.5배)로 선택할 수 있다. 첫·마지막 이미지는 선택한 기본 표시 시간보다 각각 50% 더 길게 표시한다.
- `#unconfirmed`: 이미지 전용 내보내기 실패 후 완료 더미 GIF가 생성되지 않도록 보완했다. 실제 Windows 저장 장치 오류·재시도 UX는 실사용 확인 전까지 미확정으로 둔다.

- GIF 저장 설정 기억하기의 전체 항목 복원 검증 및 보완
