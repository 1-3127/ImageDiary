# ImageDiary 버전별 구현 기능 기록

## v0.1 — MVP

- 시스템 시각 경계 기반 자동 캡처와 시작 즉시 캡처
- 순번 이미지 저장, 시간순 Animated GIF 생성, 결과 폴더 열기
- UTF-8 한글 UI와 15분·30분 캡처 간격

## v0.2 — 세션과 저장 설정

- 내부 원본 저장소와 사용자 내보내기 경로 분리
- PNG/JPG/WebP, 이미지 품질, Windows 로그인 시작, 항상 위 고정
- 미완료 세션 복구, 내부 데이터 정리, 설정 창
- 캡처 순번·수정 시각 정렬, `Diary_HHMM-HHMM.gif` 이름

## v0.3 — GIF 후처리와 사용성

- 전체 블러, 상·하단 마스킹, 반복 워터마크, 타임코드
- 내보내기 설정, 원본 이미지 동시·별도 저장, 설정 기억하기
- 캡처 대상 선택, 도움말, 앱 정보, 자동 정리 설정

## v0.4 — 안전장치와 실사용 검증

- GIF 생성·이미지 저장·캡처 저장 실패의 재시도 안내
- `.unfin` 기반 미완료 세션 보관과 이전 세션 GIF 재생성
- 통합 후처리 미리보기, 1장당 할당 시간 선택, 실제 GIF 레이어 순서 보완
- Windows 종료 안정화: 강제 이벤트 루프 종료와 미리보기 타이머를 제거
- Windows ZIP 릴리즈 배포 및 공개 저장소 전환

### 당시 보류 항목

- 이미지 전용 내보내기 실패 시 세션 보존·재시도 강화. 2026-09-17 유지보수에서 적용했다.

## v1.0 예정

v0.4 안전장치와 Windows 패키지 실사용 검증을 마친 뒤 정식 릴리즈한다.

## 유지보수

- 내보내기 설정 기억하기가 파일명 외의 경로·이미지 저장·후처리·시간 설정도 전역으로 복원하도록 수정했다. GIF 이름은 세션별 자동 이름을 유지한다.
- 2026-09-17: 이미지 전용 내보내기 실패 시 완료 마커를 만들지 않고 미완료 세션으로 보관한다. 재시도에 성공하면 완료 처리한다. GIF 후처리 오류는 이미지 없음과 구분해 표시하고, 부분 GIF가 남아도 미완료 세션으로 복구한다.
