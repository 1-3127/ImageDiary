# ImageDiary 정식 사용설명서

ImageDiary는 작업 과정을 화면 이미지와 GIF로 남기는 로컬 기반 작업 일기 도구입니다. 캡처한 이미지와 GIF는 사용자가 지정한 PC 경로에만 저장됩니다.

## 1. 시작 전 설정

`설정`에서 다음 기본값을 지정합니다. 기록 중 설정을 바꾸면 다음 세션부터 적용됩니다.

- 캡처 간격: 1분(디버그) 또는 5~30분, 5분 단위
- 캡처 대상: 전체 화면 또는 메인 모니터
- 이미지 포맷: PNG, JPG, WebP와 JPG/WebP 품질
- Windows 로그인 시 시작과 항상 위 고정
- 내부 원본 자동 정리: 보존 세션 수, 최대 용량, 마지막 활동일 기준

내부 원본은 `C:\temp\workdiary`에 저장됩니다. 자동 정리와 설정의 데이터 정리는 내부 원본만 대상으로 하며, 사용자가 지정한 내보내기 폴더는 삭제하지 않습니다.

## 2. 기록하기

1. `시작`을 누르면 현재 화면을 즉시 저장합니다.
2. 이후 시스템 시각의 다음 경계에 맞춰 캡처합니다. 예를 들어 15분 간격에서 19:07에 시작하면 19:15, 19:30, 19:45에 캡처합니다.
3. 화면의 캡처 현황은 다음 예정 시각과 캡처 순번을 보여 줍니다.
4. 기록을 끝낼 때 `종료 및 저장`을 누릅니다.

## 3. 내보내기 설정

내보내기 설정에서 GIF 이름과 저장 경로를 지정합니다. 원본 이미지 저장을 켜면 GIF와 같은 폴더 또는 별도 경로로 원본을 복사할 수 있습니다.

- 1장당 할당 시간: 0.25초, 0.50초, 0.75초 중 선택합니다. 첫·마지막 이미지는 선택 시간보다 50% 더 길게 표시됩니다.
- 블러/마스킹: 화면 전체 블러와 상단·하단 50px 검정 마스킹을 GIF에 적용합니다.
- 워터마크: 반복 문구, 선명도, 크기를 설정합니다.
- 타임코드: 캡처 시각과 날짜 표시 여부·위치·배경 선명도를 설정합니다.
- 설정 기억하기: 다음 내보내기에서 이름, 경로, 후처리와 시간 설정을 복원합니다.

`세션으로 돌아가기`는 내보내기 창을 닫고 기록을 계속합니다. `취소` 후 GIF 없이 끝내는 세션은 미완료 세션으로 보관됩니다. `GIF 없이 이미지만 내보내기`는 원본 이미지 저장을 켠 경우에만 사용할 수 있습니다.

## 4. 이전 세션 다시 내보내기

설정의 `이전 세션 GIF 다시 만들기`에서 내부 이미지가 남은 세션을 선택할 수 있습니다. 목록은 완료·미완료 상태, 일자, 이미지 수를 표시합니다. 선택한 세션은 현재 내보내기 설정으로 다시 GIF를 생성합니다.

## 5. 데이터 정리와 복구

기본 자동 정리는 최근 수정 세션 2개를 보호하고, 나머지 세션 중 마지막 활동일이 7일 이상 지난 항목을 정리합니다. 보존 세션 수·용량·날짜 기준을 함께 켜면 어느 하나에 해당하는 오래된 내부 세션부터 정리합니다.

`데이터 정리`는 확인 후 내부 저장소의 오래된 세션을 휴지통으로 보냅니다. 사용자 내보내기 폴더는 대상이 아닙니다.

## 6. 문제 해결

- 저장 경로나 설정 오류: 설정을 열어 저장 경로를 확인하거나 초기화합니다.
- GIF 생성 실패: 내부 원본을 유지한 채 재시도 안내를 사용하거나, 이후 이전 세션 다시 만들기를 사용합니다.
- 프로그램 오류: 안내 메시지의 GitHub Issue 링크를 통해 재현 절차와 오류 메시지를 제보합니다.

이미지 전용 내보내기 중 저장 장치 오류가 발생하는 예외 보존 강화는 현재 보류된 유지보수 항목입니다.

실행·저장·복구 문제는 [문제 해결](troubleshooting.md)을 참고하세요.
