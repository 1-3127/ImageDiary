# ImageDiary 간단 사용설명서

1. `설정`에서 캡처 간격, 캡처 대상, 이미지 포맷을 선택합니다.
2. `시작`을 누르면 현재 화면을 즉시 한 장 저장하고, 이후 시스템 시각 경계에 맞춰 캡처합니다.
3. `종료 및 저장`을 누른 뒤 내보내기 설정에서 GIF 이름·저장 위치·후처리를 정합니다.
4. `GIF 생성`을 누르면 결과 폴더가 열립니다.

`세션으로 돌아가기`는 기록을 계속합니다. GIF를 만들지 않고 끝내면 세션은 `.unfin`으로 보관되며, 설정의 `이전 세션 GIF 다시 만들기`에서 다시 내보낼 수 있습니다.

블러·마스킹·워터마크·타임코드는 GIF에만 적용됩니다. 내부 원본 이미지는 바뀌지 않습니다.

문제가 생기면 [문제 해결](troubleshooting.md)을 먼저 확인하세요.
