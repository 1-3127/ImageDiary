# ImageDiary 제품 소개

## 한 줄 소개

작업 과정을 자동으로 캡처하고 GIF 작업 일기로 정리하는 Windows 데스크톱 도구입니다.

## 소개 문구

ImageDiary는 작업을 방해하지 않도록 조용히 화면을 기록합니다. 시작과 함께 현재 화면을 저장하고, 선택한 시간 간격의 시스템 시각 경계마다 이미지를 캡처합니다. 기록을 끝내면 시간순 GIF로 만들어 작업 흐름을 한눈에 되돌아볼 수 있습니다.

공유가 필요한 경우 GIF에 블러, 상·하단 마스킹, 반복 워터마크, 타임코드를 적용할 수 있습니다. 원본 이미지는 내부 저장소에 유지되며 후처리는 GIF에만 적용됩니다.

## 이런 경우에 적합합니다

- 하루의 제작·코딩·디자인 작업 흐름을 짧게 돌아보고 싶을 때
- 작업 과정을 GIF 형태로 공유하고 싶을 때
- 복잡한 타임시트 없이 이미지 중심의 작업 기록을 남기고 싶을 때

## 핵심 원칙

- 시스템 시각 기준 캡처
- 로컬 저장과 사용자 제어형 내보내기
- 내부 원본과 공유용 GIF 후처리의 분리
- 작은 기능 단위와 복구 가능한 세션 관리
